🔍 Emergency Detection Rules

🚨 FALL DETECTED (Emergency)

When ALL conditions are true:

  • ✓ posture == "lying"
  • ✓ movement == "none"
  • ✓ time_on_ground > 20 seconds

✓ SAFE (No Emergency)

When ANY condition is false:

  • Person is standing or sitting
  • Person is moving normally
  • Time on ground is ≤ 20 seconds

🚀 How to Run This System
Step 1: Install dependencies $ pip install -r requirements.txt Step 2: Start Response Agent (Terminal 1) $ python response_agent.py Step 3: Start Detection Agent (Terminal 2) $ python detection_agent.py Step 4: Observe emergency detection and response - System simulates sensor data every 8 seconds - Approximately 30% of readings trigger emergencies - Watch for formatted emergency alerts and responses
