# 😊 ElderCare AI – Mood Companion Agent

> **AgentVerse Hackathon · Day 1 – Single Agent Challenge**

A caring emotional wellness companion for elderly individuals.

## Features
- 6 mood options with personalised responses
- 5 suggested activities per mood
- Daily affirmation banner
- Box breathing exercise guide
- Mood log history
- Downloadable mood report

## Run
```bash
pip install -r requirements.txt
streamlit run app.py
```

## Moods Supported
- 😊 Happy | 😔 Sad | 😰 Anxious | 😴 Tired | 😠 Frustrated | 😐 Lonely
