# 🥗 ElderCare AI – Diet Recommendation Agent

> **AgentVerse Hackathon · Day 1 – Single Agent Challenge**

Personalized diet plans for elderly based on health conditions and BMI.

## Features
- BMI calculator with category analysis
- Condition-based diet plans (Diabetes, BP, Heart, Arthritis, General)
- Daily meal schedule (5 meals)
- Foods to eat & avoid
- Downloadable diet report

## Run
```bash
pip install -r requirements.txt
streamlit run app.py
```

## Conditions Supported
- Diabetes | High Blood Pressure | Heart Disease | Arthritis | General Wellness
