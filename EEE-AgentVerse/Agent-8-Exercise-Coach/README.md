# 🏃 ElderCare AI – Exercise Coach Agent

> **AgentVerse Hackathon · Day 1 – Single Agent Challenge**

Safe, personalized exercise plans for elderly based on health condition.

## Features
- Condition-based exercise plans (5 conditions)
- Daily exercise table with duration & benefits
- Weekly schedule
- Safety precautions
- Downloadable exercise report

## Run
```bash
pip install -r requirements.txt
streamlit run app.py
```

## Conditions Supported
- General Fitness | Diabetes | High Blood Pressure | Arthritis | Post-Recovery
